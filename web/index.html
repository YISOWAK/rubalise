Le parcours de démonstration

  1. Les entrées. Les données de la course sont chargées : 6 points de passage lus dans le roadbook, 50 créneaux, 75 bénévoles traduits depuis un formulaire en texte libre.
  2. Le plan. Le solveur affecte, le vérificateur relit les règles, le contradicteur cherche ce que le code ne voit pas.
  3. La publication. Rien ne part sans confirmation explicite. Chaque décision va au journal.
  4. Le jour J. Un imprévu, une réparation avec le moins de mouvements possible, les créneaux terminés ne bougent pas.
