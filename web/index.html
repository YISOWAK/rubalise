How it works

A volunteer coordinator drops in the roadbook and the sign-up form. The assistant turns them into structured posts and volunteers, a solver computes the plan, two reviews check it, and nothing goes out unless the organizer says so. On race day, it repairs the plan with as few moves as possible.

Principles

  • The model never computes the schedule. It reads, translates, explains, and fills closed forms that code checks. Every step that uses a model is measured against a known truth.
  • Two reviews: code for the written rules, a blank-context agent for what no rule says.
  • The human keeps control by construction: publishing, waiving a rule or changing a rule all go through a confirmation checked by code, not by the prompt.
  • A published plan is a commitment: on race day every change has a cost, and the solver repairs with as few moves as possible.
  • The rules live in a file the organizer edits from the conversation. Another kind of event is another template.
